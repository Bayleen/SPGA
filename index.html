04

Tool & Warping Pose adaptation

For lifted skills, only A0 samples marked by the contact mask are anchored. In all-contact mode, every A0 stays in contact. Rod length is fixed.

Tilted places each nominal primitive with one similarity transform (Sim(3)), not point-by-point projection. Surface, Guide, Nominal, tool length and angle remain editable after generation.

0° = forward along the surface tangent; 90° = outward surface normal; 180° = backward along the tangent. Angle is measured relative to the surface, not the normal.

Both modes execute original Python M3. Fast Preview solves ~18 poses, then interpolates remaining poses for display (not scientific results). Full runs every pose; without an accelerated server it can take a long time.

FORCE BALANCE SCHEMATIC (NOT SOLVER FORCES)

Geometry pushes outward; Conic favors the Tilted axis; Ribbon resists changes between neighboring poses. These controls recompute the browser Warp and are not the calibrated Python M2 gains.

GEOMETRY FᵍOutward-only response

Deeper penetration increases repulsion. Corrections act toward the outward normal only.

CONIC RESTORING FᶜPull the tool toward the nominal axis

β controls the allowed cone; Fᶜ pulls orientation back toward the Tilted axis. The arrow shows relative gain, not measured force.

RIBBON TENSION FʳLoose arc → taut, shallow arc

Illustrative arc: SPGA Ribbon tension preserves neighboring pose relationships; it does not literally flatten the nominal path.

Tension preserves relationships between neighboring poses; bending discourages sharp changes. Both belong to Ribbon.
